# TripNavigate CRM: public test copy

This repository is the public test copy of the TripNavigate CRM application code. It exists only so the automated checks in `.github/workflows/ci.yml` can run here.

- It holds the `crm/` application folder and `.github/` exactly as they are in the private repository, without history and without project documents.
- Every test uses synthetic data only. No customer, staff or company records are here, and no secret is stored in this repository or in its settings.
- Issues and pull requests in this repository are not monitored.
